# CREATORS HQ MASTER MOD

One client-side Fabric mod for **Minecraft 26.1.2** that merges seven tools behind a single dashboard, nav bar, settings, themes and keybind system:

Easy Announce · Armour Trim & Ore Customiser · Easy TP · Easy Gamemode · Easy Enchant · Easy Give · Easy Potions

**Status: early development (~15%). Not yet compiled against 26.1.2.** Read `HANDOFF_INSTRUCTIONS.md` first, then `PROJECT_PROGRESS.md`, `TODO.md`, `BUILD_STATUS.md`.
